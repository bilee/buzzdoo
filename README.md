# Buzzdoo Task App

## 🐝 How to Get Buzzy

### Quick Start
1.  Type in "Get buzzy!"
2.  Select category
3.  Set due date (coming soon)
4.  Press Enter

## Key Features

### Word Cloud Categories
*   Categories grow larger based on usage frequency.
*   Heavy-use categories become prominent.
*   Unused categories fade.

### Smart Filtering
*   Click any task's category label to filter the list.
*   Clear filter using the X button.

### Task Management
*   Drag tasks to reorder
*   Click checkbox to complete tasks
*   Hover over tasks to reveal edit/delete buttons

### Due Dates
*   Color-coded urgency system:
    *   Red: Overdue
    *   Yellow: Today
    *   Orange: Soon
    *   Gray: Future

### Custom Categories
*   Add new categories with "+ Add category"
*   Auto-assigned unique colors for each category

### Save & Load
*   Export tasks as JSON files for backup
*   Import JSON files to switch devices or restore data

### Live Stats
*   Real-time display of completed vs. remaining tasks
*   Category-specific statistics when using filters

## Pro Tip
Add tasks across different categories to watch the word cloud visualization
come alive!
